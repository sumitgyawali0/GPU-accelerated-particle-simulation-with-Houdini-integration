## Notes for report

- **Speedup** compares average CPU frame time vs GPU kernel-only frame time (compute bound).  
- **Transfer time** is host↔device upload/download; dominates at small particle counts.  
- **Validation:** `--validate-gpu` reports max position error ~7×10⁻⁶ (Euler, gravity, 10K particles).  
- GPU advantage grows with particle count (parallel update).
